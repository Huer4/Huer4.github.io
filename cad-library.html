CAD & drawings

A collection of part models, assemblies, and their engineering drawings.

Open a drawing to inspect its dimensions, sections, and annotations, or download the corresponding CAD file. Native .prt files require compatible CAD software; assembly downloads include the accompanying .prt files from each project folder. Some model previews are embedded CAD thumbnails.

This is a selection of available drawings, not a complete drawing package for every project. The flyer currently includes only its base and valve drawings.
